# Contributing

Contributions are welcome through pull requests.

Before opening a pull request:

- Keep existing upstream copyright and license notices intact.
- Do not remove attribution for `Vinzent03/obsidian-git` or other contributors.
- Run the project checks: `pnpm run tsc`, `pnpm run svelte`, `pnpm run lint`,
  `pnpm run format`, and the test suite.
- Keep changes focused and explain behavior changes in the pull request.
- Do not include secrets, personal vault data, or generated release artifacts.

By submitting a contribution, you agree that it may be distributed under the
project's MIT License. Contributors retain copyright in their original work.
